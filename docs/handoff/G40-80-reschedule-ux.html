Flow: Gopher taps Reschedule → picks a time → sends → order shows Reschedule pending (base state unchanged). Dana gets an Approve/Decline banner with a 4-hour countdown. On Approve, the Stripe step runs per the selected case (A no-op · B extend · C-ok release + re-auth · C-fail reject + revert, with a path to update payment). On success both apps show the order rescheduled — indistinguishable from a normally-scheduled request S11. Timeout (4 hrs, no response) is treated as a decline S8.
