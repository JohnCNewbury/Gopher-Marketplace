1 · Green text — no palette green passes

The In Progress pill and the “View all” link are both green text and both fail AA. Shamrock is 2.39:1 on the pill tint; Mountain Meadow, the darkest green in the guide, only reaches 2.83:1 on white. So there is no correct-brand-green answer — each option below changes something. Pills are shown next to their siblings, because that is where the trade-off shows.

2 · The 40 components with white ink on Shamrock

Every one is 1.85:1 — the same failing pair as the step tabs, but written as a literal color:#fff rather than through the token, so item 1 did not reach them. 13 appear in both dashboards, 26 in Request only, 1 in Connect only.

This is not an invisible change. .btn-green is the primary call-to-action style, so approving all of these turns the text on every main green button from white to navy across both dashboards. That is the right call by the style guide — it is the same correction you already approved for the step tabs — but it is the most visible thing in the whole pass, so look at the right-hand column before saying go.

The highlighted row is .dash-logo-text .dlt-mark. That is part of a logo lockup, and the guide governs logo colour separately, so I would leave it alone unless you say otherwise.
