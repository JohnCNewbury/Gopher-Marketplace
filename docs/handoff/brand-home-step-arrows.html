The headline, as a template — no generation:
"You have " + n + (n===1 ? " current request" : " current requests")
+ (a ? ", " + a + (a===1 ? " needs" : " need") + " attention" : "")
→ “You have 3 current requests, 1 needs attention” · “You have 2 current requests” · “You have 1 current request”. Two numbers you already have, one string, correct for every user.
