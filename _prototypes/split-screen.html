Gopher — Request ↔ Go · live

Ready. Both apps are live and independently interactive — or use the buttons to drive the cross-app flow.
Gopher Request Requestor · left
Gopher Go Worker · right
How to drive it: click Requestor submits a request — a broadcasting request appears on the Request app (left) and an incoming-job push fires on the Go worker app (right). On the right, tap the push → open the job → Accept. The acceptance flows back and the Request app flips to “accepted / en route”. Everything else in both apps stays fully interactive. (Serve over http — the panes talk to each other same-origin.)
