Gopher · Request ↔ Go — live

Two real apps sharing one in-browser database. In the Request phone (left), tap ＋ start a request, fill in the details and submit — it appears live as a job on the Go phone (right) with a notification. Accept it there to update the request.
Requester Request app
Gopher Go app
How it works — there is no server and no fake bridge. Both phones load the real apps, empty of any demo requests, and share one browser-side store. A request you submit on the left is written to that store; the Go app reads it as a genuine Available job and raises a notification. When the Gopher opens and accepts it, that flips back through the same store and the request moves to your Active list on the left. Tap ↺ Reset demo (top-right) to wipe both phones and start fresh.
